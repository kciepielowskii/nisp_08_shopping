# 🛒 Lista Zakupów (Shopping List App)

Prosta aplikacja webowa pozwalająca użytkownikowi zarządzać listą zakupów. Projekt stworzony w celu nauki podstaw HTML, CSS i JavaScript.

## ✨ Funkcje
- [x] Dodawanie produktów do listy.
- [ ] Usuwanie produktów (w trakcie realizacji).
- [ ] Oznaczanie produktów jako kupione (w trakcie realizacji).
- [ ] Przechowywanie danych w pamięci przeglądarki (LocalStorage).

## 🚀 Technologie
- **HTML5**: Struktura aplikacji.
- **CSS3**: Stylowanie i wygląd.
- **JavaScript**: Logika i interaktywność.

## 🛠️ Jak uruchomić projekt
1. Sklonuj to repozytorium lub pobierz pliki.
2. Otwórz plik `index.html` w dowolnej przeglądarce internetowej.
3. Alternatywnie: Użyj rozszerzenia **Live Server** w Visual Studio Code.

## 📁 Struktura plików
- `index.html` - główny plik strony.
- `style.css` - arkusz stylów.
- `script.js` - logika aplikacji.
- `README.md` - ten dokument.
